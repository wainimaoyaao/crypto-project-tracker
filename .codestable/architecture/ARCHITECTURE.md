# Signal 架构总入口

> 状态：持续补录中
> 创建日期：2026-09-28

## 1. 项目简介

Signal 是一个本地运行的项目情报阅读器：服务端采集项目、市场与规则数据，浏览器端把这些数据组织为收件箱、项目详情、规则和阅读回顾界面。

## 2. 核心概念 / 术语表

- **前端渲染链**：同一页面内按固定顺序加载的传统脚本；规则通知、详情阅读和项目图表通过命名扩展注册组合，剩余渲染层仍保留少量包装。

## 3. 子系统 / 模块索引

- [前端渲染链](ui-render-chain.md)：浏览器端的共享状态、脚本顺序、函数包装层和持久化边界。

## 4. 关键架构决定

- [显式 UI 组合](../compound/2026-09-28-decision-explicit-ui-composition.md)：新增或拆分 UI 行为通过模块拥有的命名入口注册，不新增同名全局函数覆盖。

## 5. 已知约束 / 硬边界

- `dist/index.html` 中的脚本顺序仍是前端运行契约；注册方必须在其拥有者入口创建后加载，任何调整都需要回归整个渲染链。
